# KYMEET — تثبيت قالب KAYAN المعدّل (kymeet-store)

## ما الذي تغيّر؟

- التصميم والتفاعلات أصبحت داخل **حزمة القالب** `components/packs/kymeet-store/` (ملفات PHP + `assets/kymeet.css` + `assets/kymeet-luxury.css` + **`assets/kymeet-egypt.css`** + `kymeet.js` / `kymeet-ui.js`).
- من **1.7.0**: واجهة تطبيق **KYMEET Egypt** (خلفية داكنة، شاشة افتتاحية، بطاقات بيضاء للصور، شرائح تصفية، إخفاء هيدر KAYAN المكرر).
- من **1.7.1**: تعطيل **KAYAN Homepage v3** (قالب خدمات/إمارات) على الرئيسية واستبداله بأقسام KYMEET تلقائيًا — **لا حاجة لتعديل `wp-config.php` للتصميم**.
- من **1.7.2**: إيقاف **شاشة التحميل الزرقاء** (`#loader`) — كان v3 يُفعَّل عبر `template_redirect` قبل KYMEET؛ الرئيسية الآن مستند KYMEET فقط (هيرو + عطور + براندات).
- من **1.7.4**: **واجهة فاتحة** (بدون تدرج زيتي/داكن في الهيرو)، شريط سفلي **5 عناصر** (المفضلة بدل البراندات + أيقونة حسابي)، إصلاح عرض المفضلة/الحساب (إزالة `display:none`).
- من **1.7.4**: **واجهة فاتحة** (هيرو أبيض بدون تدرج زيتي)، شريط سفلي **المفضلة** بدل البراندات + **حسابي** ظاهر، إصلاح استيلاء المتجر.
- من **1.7.3**: إصلاح **ظهور كود PHP كنص** (وسم `<?php` ملتصق بالكود في 18 ملفًا)، إخفاء أخطاء `WP_DEBUG` عن الزوار، **صفحة المتجر** = واجهة KYMEET (ليس `kayan-inner` خدمات)، منع فتح ملفات الحزم مباشرة من المتصفح.
- **لا تعتمد** على إضافة `kymeet-perfumes-ui` لتحميل CSS/JS (الإضافة على الإنتاج كانت ناقصة — ملفات `assets` تُرجع 404).

## التثبيت

1. من لوحة WordPress: **المظهر → قوالب → أضف جديد → رفع قالب** واختر `dist/kayan-theme.zip`.
   - يجب أن يحتوي الـ ZIP على مجلد **`kayan-theme/style.css`** (ليس `style.css` في جذر الملف المضغوط فقط).
   - إذا ظهر «القالب لا يحتوي على style.css» أو «تعذّر تثبيت الحزمة»، استخدم ZIP من الإصدار **1.6.1+** في هذا المستودع.
2. فعّل القالب **KAYAN Theme** (الإصدار **1.7.1** في هذا المستودع).
3. **LiteSpeed Cache → Purge All** (أو مسح كاش CDN إن وُجد).
4. تأكد أن WooCommerce مفعّل وأن الصفحة الرئيسية ما زالت تستخدم ويدجتات `kymeet_*` (إعدادات KAYAN Homepage).

## تعطيل إضافة kymeet-perfumes-ui بأمان

بعد التحقق من:

- ظهور `kymeet.css` / `kymeet-luxury.css` / **`kymeet-egypt.css`** في مصدر الصفحة (Network).
- عمل `/?wc-ajax=kymeet_cart` (إضافة/عرض السلة).
- شريط التنقل السفلي (6 عناصر) والمفضلة (localStorage).

يمكن **تعطيل** الإضافة من **الإضافات** دون حذفها. لا حاجة لها لتنفيذ التصميم بعد هذا الإصدار.

## إذا ظهر خطأ بعد الرفع

| الرسالة / الأعراض | السبب المحتمل | الحل |
|-------------------|---------------|------|
| **Critical error** / شاشة بيضاء | تحميل القالب قبل WooCommerce (نوع `WC_Product` في PHP 8) | حدّث إلى **1.6.1** (تمت إزالة الاعتماد الصارم على `WC_Product` عند التحميل) |
| **headers already sent … functions.php:1** | وسم `<?` القصير (`short_open_tag=Off` على الاستضافة) يطبع نصًا قبل JSON | حدّث إلى **1.6.2** — كل ملفات PHP تبدأ بـ `<?php` |
| **تعذّر تثبيت الحزمة** / لا يوجد style.css | بنية ZIP خاطئة | استخدم `dist/kayan-theme.zip` الم rebuilt (مجلد `kayan-theme/` داخل الأرشيف) |
| **المجلد موجود مسبقًا** | استبدال القالب النشط | احذف `wp-content/themes/kayan-theme` عبر FTP أو ارفع كـ «استبدال» من المضيف |

فعّل `WP_DEBUG_LOG` مؤقتًا في `wp-content/debug.log` إن احتجت نص الخطأ الدقيق.

## التراجع

1. أعد تثبيت نسخة القالب الاحتياطية (ZIP الأصلي قبل التعديل).
2. فعّل القالب القديم وامسح كاش LiteSpeed.
3. أعد تفعيل الإضافة فقط إذا كنت تعتمد على سلوك قديم غير موجود في القالب (غير متوقع بعد هذا الإصدار).

## الاختبارات الموصى بها (يدوي على الإنتاج)

| المقياس | تحقق |
|---------|------|
| 360 / 390 / 430px | الهيرو، السلايدرات، الشريط السفلي، عدم تمرير أفقي |
| Desktop | إخفاء الشريط السفلي، قائمة الهيدر |
| السلة | إضافة، تعديل كمية، حذف، إجمالي |
| الدفع | الوصول إلى checkout (دون إتمام طلب حقيقي إن لم ترغب) |
| المفضلة | زر القلب + قسم `#kymeet-wish` على الرئيسية |
